OK, this is just for some crazy fun - and to get you active and concentrating. As you will find over and over in our courses, we want to encourage learning through doing - this is what the ACT learning approach is all about. so, are you ready to take up a challenge?


If so, then here's what you need to do. 

  • Think for a moment about why you want to learn HTML - It's important, because knowing why you want to learn something helps you better achieve it

  • When you think you know why, go here to The World's Most Dangerous Writing App

  • This is a crazy blank screen where you can write - and you are going to write the reasons why you are wanting to learn HTML

  • Select 3 minutes for "Session Length"

  • Then begin typing - but we warned, if you stop typing for more than a couple of seconds you'll lose all your work...

  • Like I said, this is about concentration - Go do it! If you're not afraid!
