This course makes use of a teaching approach called the Activated Classroom Teaching (ACT) approach. For too long lecturers and teachers have approached digital-age teaching as though it is the same as traditional offline teaching. However, it is not. Too many things have changed. 


The ACT approach is a set of teaching approaches that are designed for the digital-age, and encourage active and effective learning. This course will implement these effective approaches to ensure your learning is both enjoyable and rewarding.
