Hi everyone!

I'm committed to providing real-world, hands-on learning to maximize the value you get from this course.

To achieve this, I'll need you to follow along with me as we set up a Contentful account, which we'll use to demonstrate a local MCP server in our upcoming lesson.

While you're welcome to simply observe and still gain valuable insights, I highly recommend participating in the practical labs.

The setup process should take no more than 5 minutes.


1. Create Free Account.

  • Go to https://www.contentful.com/sign-up/

  • Choose "Free" tier

  • No credit card required

2. Use a Template (Fastest Option).

You should get a confirmation by email, click on the link and it will start onboarding, Contentful ask you a couple of questions, please don't skip them, at the end it offers example templates:

  • Select "Blog" template.

  • This auto-creates content models and sample entries (data).

3. Check if your sample content is created.

Now after the template is finished, if you click on "content model" and "content", you should see some sample data.


Write down the space ID. You should see the space ID in the URL. We'll need the space ID in the local MCP in the upcoming lecture.




4. Create API token to be used by the local MCP server.

Now navigate to

https://app.contentful.com/account/profile/cma_tokens

click on personal access token, and save the token in a secure place, we'll need it in the next lecture.
